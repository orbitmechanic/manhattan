# Textures

Organised from the original 2020 dump (111 files).  The untouched originals are
archived in `../backup/Textures_original.zip`; `rename_manifest.json` maps every
original filename to its new location.

## day/

Canonical daytime textures used by `manhattan.blend` / `.fbx` / `.obj`:

- `facades/` — ten building facade photographs, named by style + source id.
- `floors/` — one-floor crops of each facade (one window-row period).  Floor
  bands map V=0..1 per floor and U around the wall with a 12-unit module.
- `ground/` — `satellite_manhattan_ground.jpg`, recovered from the packed
  `GOOGLE_SAT_WM.tif` in the original .blend.
- `roofs/` — `roof_concrete_gravel.jpg`; roofs map world-space UVs at an
  8-unit tile.
- `streets/` — `road_asphalt.jpg`, `sidewalk_concrete.jpg`,
  `pavement_weave_roughness.jpg` (street set for road meshes / lighting tests).
- `environment/` — the original packed clear-sky HDR, kept for reference (the
  clean .blend uses a solid studio-blue world).

`../scripts/make_fog_texture.py` writes the viewer-only drifting-mist sprite to
`../viewer/assets/textures/fog_bank.png` (512×256 RGBA, soft value-noise
alpha); it is not part of the day/night facade set.

## night/

Generated by `../scripts/make_night_textures.py`, same pixel dimensions as the
day source so UVs align exactly.  There is a night variant for all 15 surface
textures used by the model plus the street set (10 facades, ground, roof,
3 streets); the environment HDR and the unused `library/` images are not
surface textures and were not night-converted.

- facades: dark blue ambient + randomly lit windows aligned to detected window
  rectangles/glazing grid.
- floors: matching one-floor night crops in `night/floors/`.
- ground: darkened satellite city + lamp glows along the road network + neon
  signage near roads.
- streets: lamp pools along kerbs, lit neon signs, faint sign reflections.
- roofs: dim ambient + a few warm skylights.

The Bevy viewer swaps day/night material sets at sunset and back at sunrise.
Night JPEGs are loaded with a repeating sampler because facade UVs are in tile
units.

## library/

All unused source images, renamed descriptively (`facade_*`, `roof_*`,
`ground_*`, `material_*`).  Includes the two `Facade00x_2K-JPG.zip` source
archives and lossless `.tif` sources for the converted street textures.
